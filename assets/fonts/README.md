# Web app fonts

| File | Used for | License |
|---|---|---|
| `FiraCode-Variable-latin.woff2` | English text, numbers, and formulas | SIL OFL 1.1 |
| `JosefinSans-VariableFont_wght.ttf` | English page headings | SIL OFL 1.1 |
| `Alexandria-Variable-arabic.woff2` | All Arabic text and headings | SIL OFL 1.1 |

All three are open-license fonts, so they ship in the repository and in every deploy.
Josefin Sans is the original file, unmodified, because its license reserves the
font name for modified versions.
